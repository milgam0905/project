첫 레벨 — 잿빛 사냥터
============================================================

1. 플레이 목표

튜토리얼 다음 단계로, 별도 서사 분기 없이 사냥과 성장에 집중한다.
오염된 늑대와 멧돼지를 처치하고 경험치를 쌓아 캐릭터 레벨 3에 도달한 뒤,
획득한 능력 포인트 6개를 배분하면 첫 레벨의 학습 목표가 완료된다.
완료 후에도 같은 맵에서 계속 사냥할 수 있다.

기본 실행은 첫 레벨이다. 기존 마을 튜토리얼은 실행 인수 --tutorial로 시작한다.
Visual Studio의 프로젝트 속성 -> 디버깅 -> 명령 인수에서 지정할 수 있다.
아무 인수도 지정하지 않으면 첫 레벨이 실행된다.

2. 조작

- WASD: 화면 기준 이동.
- SPACE / 마우스 왼쪽: 공격. 누르고 있으면 공격 간격마다 반복한다.
  사거리 1.85 월드 단위 안의 가장 가까운 보이는 적을 자동으로 향해 공격한다.
  물·나무·바위 너머의 적은 공격할 수 없다.
- E: 가까운 모든 전리품 획득. 야영지에서는 체력 완전 회복.
- Q: 회복약 1개를 소비해 HP 45 회복. 최대 HP를 넘지 않는다.
- C: 능력 창 열기/닫기. 창을 열면 전투와 이동이 멈춘다.
- 능력 창에서 1/2/3: 힘/체력/민첩에 각각 포인트 1개 배분.
- H: 안내 열기/닫기. 처음에는 안내 화면이 열린다.
- N: 야영지에서 새로운 랜덤 맵 생성. 경험치·능력·소지품은 유지한다.
- 사망 화면에서 R: 야영지 재시도. 경험치·능력 유지, 체력 회복.
- ESC: 열린 안내/능력 창 닫기. 일반 플레이 및 사망 화면에서는 종료.

3. 전투와 보상

적은 늑대 7마리, 멧돼지 7마리다. 시작 야영지 주변은 안전 구역이다.
적은 플레이어를 발견하면 추적하고, 장애물이 있으면 격자 경로를 탐색한다.
공격 전 0.45초 동안 붉은 예고 링을 표시한다. 범위 밖으로 이동하면 피할 수 있다.
피격 후 0.55초간 연속 피격을 막는다.

- 늑대: HP 32 / 기본 피해 11 / 처치 XP 25 / 금화 4.
- 멧돼지: HP 48 / 기본 피해 16 / 처치 XP 40 / 금화 7.
- 실제 피격 피해: 최대(1, 적 기본 피해 - 플레이어 방어력).
- 3마리 처치마다 회복약을 추가로 떨어뜨린다.
- 사망한 적은 18초 후, 플레이어가 해당 생성 위치에서 5단위보다 멀 때 재생성한다.
- 처치할 때만 XP를 한 번 지급한다. 전리품은 E로 획득하면 월드에서 제거한다.
- 생명 부활을 세계관 규칙으로 추가하지 않는다. 사망 후 R은 게임 플레이 재시도다.

4. 경험치와 능력 수치

시작 상태: 캐릭터 Lv.1 / 힘 3 / 체력 3 / 민첩 3 / HP 100 / 회복약 3.
다음 레벨 필요 XP = 현재 레벨 x 50.
따라서 Lv.2까지 50 XP, Lv.3까지 누적 150 XP가 필요하다.
초과 경험치는 다음 레벨로 이월하며, 한 번에 여러 레벨이 오를 수 있다.
캐릭터 레벨은 프로토타입에서 50을 상한으로 둔다.

레벨 상승 시:
- 기본 최대 HP +10.
- 기본 공격력 +2.
- 기본 방어력 +1.
- 능력 포인트 +3.
- HP 완전 회복.

능력 공식:
- 최대 HP = 60 + 체력 x 10 + 레벨 x 10.
- 공격력 = 6 + 힘 x 2 + 레벨 x 2.
- 방어력 = 레벨 + 체력 / 2 (정수 나눗셈).
- 공격 간격 = 최대(0.20초, 0.62초 - 민첩 x 0.025초).

능력 배분은 보유 포인트가 있을 때만 가능하며, 수치가 즉시 전투에 반영된다.
체력에 투자하면 늘어난 최대 HP만큼 현재 HP도 증가한다.
캐릭터 Lv.3 이상이면서 누적 배분 포인트가 6 이상이면 목표 완료로 표시한다.

5. 랜덤 맵과 접근성

크기는 40 x 36 월드 셀이다. 시작 야영지는 중앙의 고정된 안전 구역이다.
실행 또는 야영지에서 N을 누를 때 새 시드로 생성한다. 시드는 미니맵에 표시한다.

생성 절차:
1) 전체 맵을 보행 가능한 땅으로 시작한다.
2) 시작점 주변을 비운 상태로 물·나무·바위를 무작위 배치한다.
3) 배치 시도마다 시작점에서 4방향 BFS를 수행한다.
4) 모든 보행 셀에 도달하지 못하면 마지막 배치를 취소한다.
5) 마지막 방어 검사 실패 시 열린 맵으로 전환한다.
6) 연결된 보행 셀 중 야영지에서 먼 위치에 적을 배치한다.

배치 시도 횟수는 180으로 제한해 생성 과정이 무한 반복되지 않는다.
접근성은 물·나무·바위 자체가 아니라 모든 '보행 가능한 셀'을 대상으로 보장한다.
이동 충돌 반경은 0.2 셀이며, 연결된 인접 셀의 중심선을 따라 이동할 공간이 있다.
적 경로 탐색도 같은 맵 데이터와 충돌 판정을 사용한다.

6. 모델 캐싱

모델은 원·사각형·타원을 조합해 만든 2D RGBA 스프라이트다.
첫 실행에 CPU에서 생성하고, 아래 로컬 폴더에 파일로 저장한다.

%LOCALAPPDATA%\SimpleGame\ModelCache_v1\

- material_0~5.rgba: 풀·흙·석재·회벽·목재·지붕 재질.
- characters.rgba: 8팔레트 x 4방향 x 8프레임 캐릭터 아틀라스.
- level_one_models.rgba: 나무·바위·늑대·멧돼지·금화·회복약·모닥불 아틀라스.

다음 실행부터 유효한 파일이 있으면 생성 루프를 건너뛰고 읽어서 GPU에 업로드한다.
버전·크기·데이터 길이·체크섬을 검사하며, 누락되거나 손상된 파일만 재생성한다.
임시 파일에 완전히 기록한 뒤 최종 파일로 교체한다.
파일 저장이 불가능하면 메모리의 생성 결과로 플레이하고 콘솔에 알린다.
콘솔에 [cache generated] 또는 [cache loaded] 상태를 출력한다.
랜덤 맵은 매번 달라져야 하므로 모델 캐시에 포함하지 않는다.
구형 튜토리얼의 집/나무 도형 경로는 남아 있으며, 첫 레벨의 모델은 캐시 경로를 사용한다.

7. 셰이더 표현

EffectShaders.h에 GLSL 1.20 불꽃·수면 셰이더를 추가했다.
- 불꽃: 시간 기반 난류, 흔들림, 불기둥 밀도, 발광을 프래그먼트 셰이더에서 계산.
- 수면: 월드 좌표와 시간 기반 파동·물결 간섭·반짝임을 셰이더에서 계산.
- 별도 셰이더 파일 경로에 의존하지 않도록 소스를 실행 파일에 포함한다.
- 후처리(블룸·색보정 등)는 기존 Renderer 경로를 그대로 사용한다.
- 셰이더 생성 실패 시 콘솔 로그를 남기고 불꽃은 기존 CPU 표현,
  수면은 단색으로 처리한다. 정상 경로는 셰이더 기반이다.

8. 구현 파일과 범위

- LevelOneGame: 전투, 아이템, HUD, 입력, 목표 진행.
- LevelOneMap: 랜덤 생성, 연결성 보장, 충돌과 적 경로 탐색.
- RpgStats: 경험치, 레벨업, 능력 포인트, 파생 능력 공식.
- AssetCache / RenderAssets: 모델 생성, 파일 캐시, 텍스처 업로드.
- Renderer / EffectShaders: 렌더링과 시간 기반 셰이더 이펙트.
- GameMode: 첫 레벨과 기존 튜토리얼에 공통으로 적용되는 실행 인터페이스.
- UiText: 한국어 UI. 변화하는 수치 문자열의 텍스처 캐시 개수를 제한한다.

현재 진행 정보는 실행 중 메모리에 유지한다. 종료 후 XP·소지품을 복원하는
세이브/로드, 장비 교체, 상점, 영구적인 월드 변화는 이번 구현에 포함하지 않는다.
모델 파일 캐시는 실행을 종료해도 유지된다.

9. 직접 확인할 항목

- 기본 실행 시 첫 레벨, --tutorial 시 기존 튜토리얼이 열린다.
- WASD, Space/좌클릭 공격, E 획득, Q 회복이 동작한다.
- 벽 너머 공격이 불가능하고, 적의 예고 공격을 이동으로 회피할 수 있다.
- 처치 XP가 한 번만 지급되고 레벨업 시 수치와 포인트가 증가한다.
- C 능력 창의 배분이 공격력/최대 HP/방어/공격 간격에 즉시 반영된다.
- Lv.3 및 6포인트 배분 후 목표 완료가 표시된다.
- 새로운 시드에서도 모든 보행 셀이 연결되고 적과 전리품에 접근할 수 있다.
- 두 번째 실행에서 캐시 로딩 로그가 표시된다.
- 불꽃과 물결이 시간에 따라 움직이며, 후처리 이후 UI가 선명하다.

코드 컨벤션은 루트 .clang-format을 따른다.
사용자 작업 원칙에 따라 빌드·실행·화면 결과 확인은 수행하지 않는다.
