튜토리얼 프로토타입 — 잔향의 마을 / 마지막 한마디
작성일: 2026-09-09 | 개정: 렌더링 확장 v0.2
============================================================

1. 목표

중세 다크 판타지 마을에서 시작하는 싱글 플레이 쿼터뷰 2.5D 튜토리얼.
WASD 이동과 상호작용을 익히며 생명·죽음·등가교환이라는 게임 주제를 경험한다.
필수 동선은 5분 이내, 목표 체험 시간은 3~4분이다.
시간은 설계 추정이며 실제 플레이 측정값이 아니다. 실패 제한시간은 두지 않는다.
주민 전체와 대화하거나 자유롭게 머무는 시간은 필수 동선에 포함하지 않는다.

2. 조작

- WASD: 화면 기준 상하좌우 이동. 대각선 속도는 정규화한다.
- E: 가까운 주민과 대화, 약초 채집, 제단 조사. 대화 중에는 다음 페이지.
- SPACE: 대화의 다음 페이지.
- 1: 호수에서 자신의 기억을 대가로 지불한다.
- 2: 거래를 거절하고 작별한다.
- H: 도움말 열기/닫기.
- ESC: 도움말/일반 대화를 닫는다. 일반 탐험 중에는 게임 종료.
  선택 대화에서는 선택 화면까지 넘기며, 선택 자체는 1 또는 2로 결정한다.
- R: 퀘스트 완료 후 전체 튜토리얼 재시작.

대화와 도움말 중 이동을 멈춘다. 창이 포커스를 잃으면 이동키 상태를 해제한다.
금색 표식과 미니맵이 다음 목표를 안내하고, 상호작용 가능 거리에서 E 안내를 표시한다.

3. 레벨 구성

시작 위치: 작은 마을 광장의 남쪽. 주인공은 손등불을 들고 있다.
마을: 지붕과 벽면이 구분되는 집 9채, 등불과 모닥불, 주민 16명, 연결된 흙길.
숲: 마을 왼쪽 위. 은빛잎이 있는 짧은 길은 나무 배치에서 제외해 통로를 확보한다.
호수: 마을 오른쪽 위. 물가 제단과 어부가 있으며 수면에는 낯선 별빛이 비친다.
마을·숲·호수는 한 레벨 안에서 로딩 없이 이동한다.
전체 경계는 X -28~28, Y -26~26으로 기존 28x26에서 56x52로 면적이 4배다.
퀘스트 목적지는 기존 위치를 유지하고, 확장 지역은 선택 탐험 구역으로 둔다.
곡선 산책로와 자연스러운 호숫가를 사용하며, 지면에는 타일 경계를 그리지 않는다.
물, 건물의 바닥 영역, 나무 줄기와 월드 경계에 충돌을 둔다.

주요 월드 좌표:
- 시작: (0, 3)
- 장의사 마라: (0, 0)
- 은빛잎: (-8, -5)
- 호숫가 제단: (6, -7)
- 호수 중심: (11, -6)

4. 필수 퀘스트 흐름과 예상 시간

00:00~00:30  이동과 대화 익히기
  목표 표식을 따라 마라에게 접근하고 E를 누른다.
  오늘 죽은 뱃사공의 장례를 위해 은빛잎을 제단에 놓아 달라는 부탁을 받는다.

00:30~01:20  숲길과 채집
  숲의 은빛잎을 E로 채집한다. 새순을 남기는 장면으로 생명의 연속성을 표현한다.
  목표와 소지품 표시가 갱신된다. 약초꾼의 대화는 선택 사항이다.

01:20~02:40  호수와 등가교환
  제단에 은빛잎을 놓으면 미지의 목소리가 거래를 제안한다.
  죽은 사람을 되살려 주지는 못하지만, 마지막 말은 건져 줄 수 있다고 한다.
  대가는 플레이어 자신의 가장 따뜻했던 하루의 기억이다.
  그 말이 정말 뱃사공의 것인지는 검증할 수 없다.

  선택 1: 기억을 내주고 “내 자리를 비워 두지 마”라는 말을 듣는다.
  선택 2: 거래를 거절하고 향을 피워 작별한다.
  어느 선택에서도 죽은 사람은 완전히 부활하지 않는다.
  대가는 선택 전에 명시하며, 다른 주민에게 전가하지 않는다.

02:40~03:40  귀환과 완료
  마라에게 돌아오면 선택에 따른 결말 대화가 나온다.
  거래했다면 잃은 기억과 얻은 말의 무게를, 거절했다면 알 수 없음과 애도를 다룬다.
  완료 배너 표시 후 마을에서 계속 걸어 다니거나 R로 다른 선택을 체험할 수 있다.

시간 추정에는 길 찾기와 대화 읽기를 포함한다. 강제 대기나 시간 끌기는 없다.

5. 주민 16명과 야생 동물

- 장의사 마라: 퀘스트 의뢰와 완료. 따뜻하지만 현실적인 태도.
- 빵 굽는 오렌: 외상 농담 뒤에 뱃사공을 잃은 아쉬움을 드러낸다.
- 견습 장의사: 촛불은 남은 사람이 혼자 있지 않도록 켠다고 말한다.
- 목수 브람: 숲길과 물가 위험을 안내한다.
- 경비병 세라: 호숫가 방향을 알려 주고 젖은 장화에 대한 농담을 한다.
- 뱃사공의 딸: 부활을 바라면서도 타인의 희생은 원하지 않는다. 완료 후 대사가 바뀐다.
- 어부 노엘: 물속 별과 자신의 이름을 아는 목소리에 대해 이야기한다.
- 약초꾼 이브: 필요한 잎만 채집하고 뿌리는 남기라고 말한다.

추가 주민: 대장장이 로크, 양치기 미라, 직조공 엘렌, 행상인 토마,
수습 수도사, 벌목꾼 헤른, 도공 아샤, 순례자 벤. 각각 별도 한국어 대사가 있다.
기존 8명은 안내와 퀘스트 접근성을 위해 자리를 지킨다.
추가 8명은 집 주변을 걷고 플레이어가 가까이 오면 멈춘다.

캐릭터는 4방향, 방향당 8프레임(대기 1 + 걷기 7)의 스프라이트 아틀라스를 사용한다.
모자·얼굴·스카프·튜닉·팔·허리띠·다리·장화와 의복 팔레트를 구분한다.
사슴·여우·토끼 각 3마리, 총 9마리가 확장된 숲과 초원에 배치된다.
야생 동물은 주변을 배회하고 가까이 접근한 플레이어로부터 달아난다.
건물·나무·물·월드 경계를 피하는 간단한 이동이며, 전투/사냥/드롭 기능은 없다.

6. 렌더링 방향과 현재 구현 방식

기존 Renderer.cpp가 월드 렌더링의 중심이 되도록 통합했다.
- 바닥: 반복 가능한 풀·흙 재질, 연속 곡선 길, 자연스러운 자갈 광장.
- 건물: 석재 기단, 회벽, 목재 골조, 판재 문, 풍화된 지붕 재질, 나무통과 굴뚝.
- 숲: 불규칙 배치와 둥근 수관, 미세한 흔들림, 근접 시 가림 완화.
- 그림자: 모든 오브젝트보다 먼저 지면에 접촉 그림자와 부드러운 투영 그림자.
  건물은 발자국 형태의 방향성 그림자를 추가하며, 물리 기반 섀도맵은 아니다.
- 수면: 연속적인 불규칙 해안선, 얕은 물/깊은 물 색 변화, 잔물결과 수면 반짝임.
- 불꽃: 모닥불·등불·주인공 손등불·제단의 불꽃과 날리는 불티, 가산 발광.
- 캐릭터: 코드로 생성하는 RGBA 스프라이트 아틀라스의 프레임 애니메이션.
- 후처리: 장면 FBO -> 밝은 영역 추출 및 가로/세로 블러 -> 블룸 합성,
  차가운 그림자/따뜻한 밝은 부분 색보정, 비네트, 간단한 가장자리 완화.
- UI: 후처리 합성이 끝난 뒤 한국어 텍스트와 패널을 그려 가독성을 유지한다.

재질과 캐릭터 아틀라스는 RenderAssets.cpp에서 실행 시 생성한다.
외부 이미지 파일이나 다운로드는 필요하지 않으며, 완성 아트로 추후 교체 가능하다.
한국어는 Windows 글꼴을 GDI로 래스터화해 OpenGL 텍스처에 저장한다.
호수의 렌더링과 이동 충돌, 길과 나무 배치가 WorldGeometry.h의 동일한 곡선을 참조한다.

OpenGL 2.1 호환 렌더링을 유지한다. 후처리는 OpenGL 3.0 또는
ARB_framebuffer_object 확장 지원이 필요하며, 초기화 실패 시 콘솔에 안내하고
기본 월드 렌더링으로 전환한다. 구형 SolidRect GLSL 파일은 실행 경로에서 사용하지 않는다.
화면 캡처·실행 성능·플레이 시간은 사용자가 직접 확인한다.

7. 파일과 실행 준비

- SimpleGame/SimpleGame.cpp: 창, 키 입력, 타이머와 게임 수명 연결.
- SimpleGame/TutorialGame.h 및 TutorialGame.cpp: 레벨, 이동, 대화, 퀘스트, 주민·동물 AI.
- SimpleGame/Renderer.h 및 Renderer.cpp: 지형·건물·그림자·캐릭터·이펙트·후처리.
- SimpleGame/RenderAssets.h 및 RenderAssets.cpp: 재질과 스프라이트 아틀라스 생성.
- SimpleGame/WorldGeometry.h: 맵 경계, 곡선 길과 호숫가의 공통 정의.
- SimpleGame/SimpleGame.vcxproj: 새 소스 등록, 한국어 UTF-8 컴파일, OpenGL 링크.

사용자가 Visual Studio에서 솔루션을 빌드하고 실행한다.
기존 구성처럼 실행 파일 옆에 해당 아키텍처의 freeglut.dll과 glew32.dll이 필요하다.
저장/불러오기, 전투, 장비·성장, 여러 청크의 스트리밍은 이번 좁은 시제품 범위 밖이다.
퀘스트 진행과 소지품은 실행 중에 유지되며, 재시작이나 종료 시 초기화된다.

8. 사용자가 직접 확인할 완료 기준

- 시작 화면에 마을과 주민이 보이고 WASD가 화면 기준 방향으로 동작한다.
- 집과 호수를 통과하지 않으며, 숲의 약초와 호수 제단에 접근할 수 있다.
- 주민 16명과 대화할 수 있고 대화 중에는 이동하지 않는다.
- 새 주민은 배회하며, 야생 동물 9마리가 물·건물에 들어가지 않고 접근 시 달아난다.
- 풀·흙·목재·석재 재질, 부드러운 그림자, 캐릭터 방향과 걷기 프레임을 확인한다.
- 호숫가 곡선과 충돌이 일치하고 길에 나무가 통행을 막지 않는지 확인한다.
- 후처리 후에도 한국어 UI가 선명하고, 불꽃·수면·안개가 정상적으로 움직이는지 확인한다.
- 의뢰 -> 채집 -> 제단 -> 선택 -> 귀환 순서로 목표가 갱신된다.
- 두 선택 모두 완료할 수 있고 결말과 뱃사공 딸의 후속 대사가 다르다.
- 창 크기 변경 후에도 쿼터뷰 비율과 한국어 안내가 유지된다.
- 다른 창으로 전환했다 돌아왔을 때 캐릭터가 저절로 걷지 않는다.
- 완료 후 R로 재시작하면 첫 위치와 의뢰 전 상태로 돌아간다.
- 필수 동선의 실제 소요 시간이 5분 이내인지 측정한다.

사용자 작업 원칙에 따라 Codex는 빌드·실행·화면 결과 확인을 수행하지 않는다.
