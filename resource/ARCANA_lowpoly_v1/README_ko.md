# ARCANA 로우폴리 그래픽 리소스 v1

Blender 5.2.2 LTS에서 제작한 모듈형 스켈레탈 캐릭터·동물 및 중세 생활·자연 환경 세트입니다. 모든 산출물은 이 폴더 안에 있습니다. 게임 소스나 원본 스토리 DB는 수정하지 않았습니다.

## 시작할 파일

## 인간 조립

키 1.80m, 머리 높이 0.257m의 7등신 공용 인간 리그 `ARC_Human_v1`입니다. 모든 부위는 같은 바인드 포즈·원점·본 이름을 사용합니다. 원본은 A 포즈이며 실제 대기·이동 포즈에서는 팔을 내립니다.

`head / face / hair / neck / torso / hands / legs / boots / belt / outer / weapon` 슬롯마다 한 부위를 선택합니다. `outer`, `weapon`은 선택 사항입니다. 앞치마와 갑옷은 같은 `outer` 슬롯이므로 동시에 사용하지 않습니다. 후드는 머리카락 슬롯을 대체합니다. 피부색은 머리·목·손·얼굴 접미사를 맞춥니다. 얼굴에 접미사가 없으면 중간 피부색입니다.

Blender에서는 원본 `.blend`에서 필요한 부위의 표시를 켜고 다른 부위를 숨기는 방식이 가장 간단합니다. 대체 부위들은 같은 위치에 겹쳐 저장되어 있으며 기본으로 주인공 조합만 보입니다. 신체와 의복은 공유 리그에 스킨되어 있고 얼굴·머리카락·작은 장비는 해당 본에 강체 가중치로 연결됩니다. 얼굴은 교체 가능한 로우폴리 장식 메시이며 표정·입 모양 애니메이션은 없습니다.

개별 GLB에는 독립적으로 확인할 수 있도록 공용 리그와 9개 애니메이션이 함께 들어 있습니다. 여러 부위 GLB를 Blender에 각각 임포트하면 리그도 중복됩니다. 최종 조립에서는 리그 하나를 유지하고 부위의 Armature 대상·부모를 그 리그로 연결한 뒤 중복 리그를 제거해야 합니다. 이름만 같은 본을 서로 다른 리그 인스턴스에 남기지 마세요. 부위의 바인드 좌표를 임의로 이동·스케일하지 않습니다.

`socket_hand.R`, `socket_back`, `socket_belt`를 장비 부착 기준으로 제공합니다. 현재 검·망치는 손 본에 스킨된 교체 장비입니다. NPC 네 가지는 조합 예시이며 DB의 모든 고유 NPC 외형을 개별 제작했다는 의미는 아닙니다.

## 동물 조립과 분류

| 동물 | 식성·성향 디자인 | 형태 |
| --- | --- | --- |
| 사슴 | 초식·순한 동물 | 가는 다리, 앞쪽 슬관절과 뒤쪽 비절, 갈라진 발굽, 탈착식 사슴뿔 |
| 늑대 | 육식·위험 동물 | 지행성 뒷다리, 발바닥·발가락, 긴 꼬리, 목 털 장식 |
| 멧돼지 | 잡식·위협 시 위험 | 낮고 무거운 몸통, 짧은 다리, 엄니와 등 갈기 |
| 염소 | 초식·중립 동물 | 올라간 비절, 갈라진 발굽, 휘어진 뿔과 턱수염 |

각 종은 독립적인 리그와 9개 Action을 가집니다. 같은 종·같은 리그 버전 안에서만 몸통·다리·머리·꼬리·장식을 바꿉니다. 다리 비율과 바인드 행렬이 달라 종간 부위 교환은 지원하지 않습니다. 사슴의 뿔을 끄면 무각형 조합으로 사용할 수 있습니다. 성향 분류는 외형·리소스 정보이며 AI 행동은 포함하지 않습니다.

## 애니메이션과 조합

인간과 네 동물 모두 `Reference / Idle / Walk / Run / Turn_L90 / Turn_R90 / Turn_Base / Attack / Jump`를 제공합니다. 인간 바인드 클립 이름은 `HUM_Reference_A`입니다. 30fps이며 걷기·뛰기는 제자리 애니메이션입니다. 각 파일의 Action은 Blender의 Dope Sheet → Action Editor에서 고릅니다.

기계가 읽을 수 있는 상세 정보는 `metadata/animation_blending.json`에 있습니다. 클립 프레임, 접지 위상, 이동 기준 속도, 전환 시간, 회전 보간 기준, 점프·공격 타이밍을 담았습니다. 이벤트는 메타데이터이며 게임 코드에서 실행되는 이벤트가 아닙니다.

- 대기 → 걷기: 약 0.18초로 전환하고 왼발 또는 왼앞발 접지에서 시작합니다.
- 걷기 ↔ 뛰기: 약 0.20~0.24초 동안 혼합하며 정규화한 보행 위상을 공유합니다. 실제 월드 이동 속도도 혼합한 보폭에 맞춥니다. 인간의 기준 걷기 속도는 약 0.73m/s, 뛰기는 약 2.70m/s입니다.
- 사슴·염소의 달리기는 도약형 보법이므로 걷기와 접지 순서가 다릅니다. 뒷발 접지 부근에서 전환하고 최종 게임에서는 지형·발 고정을 추가하는 것이 좋습니다.
- 좌우 회전은 루트 회전 ±90도를 포함합니다. 루트 회전을 캐릭터 제어기에 누적했다면 다시 같은 회전을 더하지 않습니다. 회전 완료 후 새 방향을 제어기에 남기고 다음 대기 클립의 루트로 전환합니다.
- `Turn_Base`는 팔을 내린 중립 기준 포즈입니다. 가산 회전에 사용할 때 각 본의 로컬 회전 차이를 이 포즈 기준으로 계산합니다. 쿼터니언은 부호를 맞춘 최단 경로 slerp를 사용합니다.
- 점프는 웅크리기·도약·공중·착지·회복과 수직 루트 이동을 포함합니다. 수평 이동은 외부에서 유지합니다. 물리 점프로 높이를 제어한다면 애니메이션 수직 이동을 중복 적용하지 않습니다.
- 공격은 전신 1종씩입니다. 인간은 오른손 휘두르기, 동물은 종별 물기·머리/엄니 들이받기 동작입니다. 검·망치에 별도 공격 세트를 제작한 것은 아닙니다.

지형 대응 IK, 발 고정, 지형에 따른 회전 접지 보정, 전투 판정, 애니메이션 믹서·상태 머신은 별도 게임 구현 대상입니다. 좌우 이동·후진·피격·사망·수영 클립은 이번 목록에 포함하지 않았습니다.

## 주거 환경 모듈

25cm 스냅 그리드, 벽 너비 2m·높이 2.5m, 바닥 2×2m 기준입니다. 원점·연결점은 `metadata/building_sockets.json`을 참고합니다. 벽은 왼쪽 아래가 원점이고 +X로 이어집니다. 지붕은 +Y 방향으로 처마에서 용마루로 올라가며 반쪽 폭 2m·높이 1.25m입니다. 문·창문은 실제 구멍이 있습니다.

기초·판자 바닥·민벽·문벽·창벽·기둥·보·박공지붕·초가/목재 지붕·용마루·굴뚝·울타리·계단·덧문을 조합합니다. 완성 집은 조합 예시이며 가구는 지붕 안쪽에도 배치되어 있습니다. 완성 집의 문은 정적 문입니다. 동적 문이 필요하면 해당 메시를 `door_rigged`로 바꾸고 힌지 원점을 맞춥니다.

생활 자원에는 탁자·의자·걸상·긴 의자·침대·선반·닫힌/열린 나무 궤짝·통·양동이·토기·그릇·자루·모루·망치·도끼·삽·쇠스랑·장작·등불·우물이 포함됩니다. `chest_rigged`는 별도로 뚜껑을 열고 닫을 수 있습니다. 문과 상자는 `Closed / Open / Close / Hold_Open` 4개 클립을 제공합니다. 정적인 집과 도구에는 보행 리그를 붙이지 않았습니다.

## 자연과 재질

소나무·어린 가문비·큰 참나무·어린 참나무·고사목·그루터기·쓰러진 통나무·바위 3종·풀 군락 3종·고사리·관목·갈대·버섯 및 흙/풀/돌/길 지면 타일을 제공합니다. 자연 메시의 바람 애니메이션은 포함하지 않습니다.

목재·수피·돌·흙·풀·회벽·초가·이끼 8종 재질에 각각 512×512 Base Color, Roughness, Normal 이미지를 제공합니다. 주기적 패턴으로 반복할 수 있습니다. Base Color는 sRGB, Roughness/Normal은 Non-Color, 노멀 맵은 OpenGL +Y 규약입니다. 재질 `.blend`에는 이미지가 내장되어 있습니다. 환경 GLB는 사용한 재질과 이미지도 내장합니다.

캐릭터는 탁한 모직·린넨·가죽·철·황동의 단색 PBR 재질로 구성됩니다. 환경 UV0는 1m/UV 단위의 박스 투영이며 타일 재질용으로 의도적으로 겹칩니다. 유일한 페인팅 UV 아틀라스나 베이크된 조명 맵은 아닙니다. 식물은 알파 텍스처 없이 불투명 로우폴리 도형으로 제작했습니다.

Blender: Z 위·-Y 전방. GLB: Y 위·+Z 전방. 모든 치수는 미터입니다. C++/OpenGL/2.5D 렌더러로의 로더 연결이나 스프라이트 변환은 이 리소스 세트에 포함되지 않습니다.

## 확인과 재제작

`metadata/validation.json`에는 GLB 형식·유한 좌표·스킨 가중치·UV·애니메이션 존재, Blender 루프 양끝 행렬과 이동 관절 연결 검사 결과가 기록됩니다. 미리보기는 Blender 렌더입니다. 실제 게임 안에서의 외관·충돌·성능은 별도 확인 대상입니다.

`_authoring/`의 Python 파일은 Blender 내부에서 이 리소스만 재제작하기 위한 저작 도구입니다. 게임 코드가 아닙니다. 실행 순서는 `materials.py → humans.py / animals.py / environment.py / interactives.py → validate.py → finish_metadata.py`입니다. 재실행하면 이 v1 세트의 동일 이름 파일을 덮어쓰므로 수동 편집본은 먼저 다른 이름으로 보관합니다. 원본 제작 폴더 바깥으로 산출물을 저장하지 않도록 임시 파일 경로도 내부에 지정했습니다.

동작 미리보기는 Blender에서 `pose_previews.py`를 실행한 다음 Pillow가 있는 Python에서 `assemble_previews.py`를 실행해 재생성합니다. `finalize_actions.py`는 최종 검토 때 기존 메시를 유지한 채 공격 포즈만 갱신하기 위해 사용한 보조 도구입니다. 현재 `humans.py`와 `animals.py`에도 해당 수정이 반영되어 있습니다.
