# 레나 시작 맵 — 아르카 수로의 생존자

## 실행

보존된 레나 모드는 `--lena`로 실행한다. 현재 인자 없는 기본 실행은 ARCANA이며 `ARCANA_INTEGRATION.md`를 참고한다. 창 제목은 공통 게임 이름 `아르카나 : ARCANA`다.
기존 확장 튜토리얼은 `--tutorial` 또는 `--village`, 사냥터는 `--level-one`으로 보존한다.
여러 모드 인자가 있으면 마지막 인자가 우선한다. Visual Studio 디버깅 인자에 옛 모드가 있으면 지우거나 `--lena`로 변경한다.

레나 시작 맵은 이전 튜토리얼을 재명명한 것이 아니라 별도 `LenaGame` / `Lena::World` 구현이다.
`docs/story1.md`의 아에리아 도입부를 사용한다. 기존 모드의 장례·호수 퀘스트를 새 모드로 이식하지 않는다.
생명은 복원 가능한 아이템이 아니며 사망, 기억, 남은 사람의 대가라는 기존 주제는 유지한다.

## 배치와 첫 흐름

- 52×52 월드 단위의 고정 레나 계곡. 시작점은 북서쪽 아르카 수로(-17,-17).
- 중앙 레나 광장·창고 게시판(0,5), 농경지와 진료소, 동쪽 사슴 숲(15,12), 북동쪽 늑대 능선(22,20), 호수·음수 지점(8,-7).
- 새 건물·나무 배치와 곡선 길, 잔디·흙·돌 재질을 사용한다. 물결과 수로의 신비한 불꽃은 기존 셰이더, 인물은 기존 스프라이트/모델 캐시를 재사용한다.
- 충돌 격자는 0.5단위. 수로 시작점의 연결 영역으로 제한하고 스폰 위치를 그 영역에 보정한다. AI와 플레이어가 동일한 보행·사선 조건을 사용한다.
- 레나 주민 84명 = 리아·에드윈·마라·다리안·노아·셀린 + 일반 주민 78명. 마을 외부 약탈자 4명은 테스트 가능한 위협으로 별도 배치한다. 늑대 7마리, 사슴 32마리, 플레이어 1명. 모든 개체는 고유 Actor다.
- 여섯 주요 인물의 7개 성격 수치는 원문을 사용한다. 주민 78명을 코호트로 축약하지 않고 개별 시뮬레이션한다. 익명 주민의 직종·세부 위치와 약탈자 4명은 이번 맵의 구현용 배치다.
- 문서는 실행 시 eval/파싱하지 않는다. 첫 맵에 필요한 ID·수치는 C++ seed에 명시적으로 반영했다. 문서 수정만으로 실행 데이터가 자동 변경되지는 않는다.

`EVT_P001`: 리아를 믿고 동행 / 혼자 출구 찾기. 동행은 생존한 리아가 가까이 있어야 한다. 30 world minutes가 지나면 구조 기록을 남기는 미개입 경로가 열린다. 플레이어를 자동으로 동행 선택시키지 않는다.

`EVT_P002`: 레나 게시판에서 수로 우선 / 숲 우선 선택. 양쪽 단서는 E로 조사 가능하다. 선택하지 않고 120 world minutes가 지나면 주민 조사 결과를 게시판 경로로 제공한다. 이 자동 조사 결과는 첫 맵의 요약 처리이며 실제 조사대 구성·노동 예약까지 구현한 것은 아니다.

`EVT_A102`의 첫 맵 대응: 세계 시간 180분 이후 숲 현장에서 [1] 120분 통로 복구 작업 또는 [2] 경비가 참여하는 늑대 사냥. 복구는 플레이어가 현장에 머물고 주변 전투가 없을 때만 진행한다. 사냥 결과는 실제 공격으로만 결정한다. 통로 복구는 사슴의 이동 중심을 옮기며 배고픔을 즉시 없애지 않는다.

첫 맵의 미개입은 두 원인에 대한 단서를 보존한다. 주요 NPC의 사망은 되돌리지 않으며 개인 대화는 사라진다. 에드윈 사망 시 게시판, 리아 사망 시 수로 기록이 탐색을 이어준다. 720분 전에는 수로의 완전한 에덴 이름을 공개하지 않는다.

## 상호 영향

| 관계 | 행동과 결과 |
| --- | --- |
| 늑대 → 사슴 | 배고픔에 따른 탐색·접근·공격. 먹이 사망 후에만 사체의 유한 열량 소비 |
| 사슴 → 늑대 | 도주 우선, 가까운 위험·막힌 퇴로에서 반격. 반격도 치명상이 될 수 있음 |
| 늑대 → NPC | 심한 기아와 가까운 대상 조건에서 사람을 먹이 후보로 삼음. NPC는 도주·반격·보호 반응 |
| NPC → 늑대 | 경비가 목격한 인간 위협에 개입. 사냥 선택 후 경비의 사냥 대상 확장 |
| 약탈자 → NPC | 위협 후 실제 식량 절도 또는 공격. 피해자와 목격자는 공포·기억·도주·신고로 반응 |
| 경비 → 약탈자 | 관측한 공격에 개입. 저용기 약탈자는 저체력에서 항복, 근처 경비가 구금 상태로 전환 |
| NPC → NPC | 실제 약품을 소모한 치료, 식량·은화의 쌍방 거래, 소식 전달, 애도, 신고 전달 |
| 플레이어 → 생명체 | 근접 대상에게 공격 가능. 주민도 죽을 수 있고 목격된 폭력은 신고 대상. 항복 수용 대상에 대한 공격은 제한 |

공격과 의도적 Kill은 구분한다. 첫 맵의 인간에게는 확정된 처형 명령/살해 목표를 부여하지 않아 인간 Kill은 허용하지 않는다. **인간끼리 Attack으로 치명상을 입혀 죽이는 것은 가능하다.** 늑대 Kill은 체력 12 이하 먹이, 기아 70 이상, 2초 이상 사냥 지속, 사거리·사선 재확인 조건이다. 사슴 Kill은 불가하다.

사망 처리에서 dead를 한 번만 전환하고 행동을 중단한다. 원래 Actor가 사체 컨테이너가 되어 소지품과 열량을 보관하므로 별도 복제품을 생성하지 않는다. 사체 먹이와 유품 수거는 유한 수량을 차감한다. 레나 인구는 살아 있는 소속 주민으로 집계되어 사망 시 한 번 줄어든다. 자동 리스폰이나 불사 체력 하한은 없다.

사건 사실과 NPC 인지는 구분한다. 가까운 사선 안의 실제 사건 또는 발견한 시체만 기억에 들어가고, 오래된 시체만 보고 범인을 자동 식별하지 않는다. 대화는 같은 fact ID를 전달하여 중복 증거로 세지 않는다. 신고는 경비에게 실제로 도착해야 접수되며 같은 사건의 치안 감소는 한 번이다. 소문만으로 자동 처형하지 않는다.

매 시간 실제 노동 위치의 주민을 기준으로 식량 생산, 창고→개인 배급, 결핍·오염 노출을 처리한다. 사망한 노동자는 생산에서 빠진다. 늑대 멸종 후 사슴이 많이 남으면 농작물 피해가 생긴다. 식물은 사슴이 소비하고 시간에 따라 회복한다. 극심한 결핍은 천천히 건강을 깎고, 사망도 공통 사망 처리를 사용한다.

## 조작과 저장

- H: 안내/일시정지. 안내가 열린 동안 세계 시각과 AI는 멈춘다.
- WASD: 화면 방향 이동. SPACE/좌클릭: 가까운 대상 공격.
- E: 수로·숲·게시판 조사, 가까운 NPC 대화/치료, 유품 수거, 수원에서 음수.
- Q: 보유 식량 1배급 소비. 음수는 갈증과 함께 오염 노출에 영향을 준다.
- 1/2: 현재 사건의 명시적 선택. 숲 작업은 현장에서만 선택한다.
- K: 전체 상태 저장. L: 저장 상태 불러오기. R: 새 세계 시작(현재 진행 초기화, 저장 파일은 삭제하지 않음).
- ESC: 종료. 자동 저장은 하지 않는다.

저장 경로: `%LOCALAPPDATA%\SimpleGame\lena-save-v1.txt`. 환경 변수가 없으면 실행 디렉터리의 같은 파일을 사용한다.
UTF-8 JSON 모니터와 별개인 버전 명시 텍스트 슬롯이다. 임시 파일을 완성한 뒤 교체한다.
시간·틱·사건 번호·모든 개체 위치/건강/인벤토리/행동/인지 사실·사망 사실·신고 여부·마을 자원·퀘스트 선택/작업 시간을 함께 저장한다.
로드 시 별도 임시 데이터로 형식·참조·사망 중복을 검사한 뒤 한 번에 반영한다. 깨진 파일은 현재 세계를 변경하지 않는다.
경로 탐색 캐시는 로드 후 다시 계산하므로 프레임 단위 궤적의 완전 재현을 보장하지 않는다. 오프라인 시간은 진행하지 않는다.
플레이어 사망 시 세계 전체를 멈추고 L로 일관된 전체 저장 상태를 복원하거나 R로 새 세계를 시작한다.

## 모니터와 성능

world_id 기본값은 `WORLD_AERIA_LENA`, 마을 ID는 `SET_LENA`다. 주요 NPC ID는 문서의 `NPC_LIA` 등의 값을 사용한다. 야생동물·외부 약탈자는 레나 주민 수에 넣지 않는다. 모니터의 전체 NPC 수는 주민 84+외부 약탈자 4이며 마을 카드의 주민 수는 84로 시작한다.

체력, 사망, 행동, 대상, 공포·슬픔·노출, 사체 열량, 인지한 사건 수, 항복·구금 상태를 관측한다. 마을 창고 식량·사기·치안·오염은 실제 시뮬레이션 값이며 경제 종합 지수는 미수집이다.

AI 판단은 약 1초, 근접 후보 색인은 0.25초 단위다. 카메라 밖 개체도 동일 규칙으로 계속 진행한다. 거리 기반 전체/추상 LOD는 아직 없다. 경로 탐색은 업데이트당 최대 2회이며 초과 요청은 다음 단계로 넘긴다. 모든 배치는 SceneGraph, 그리기는 RenderQueue를 사용한다.

## 이번 범위 밖 — 문서 전체 구현과 구분

이 맵은 **프롤로그 두 사건과 첫 숲 대응, 세 종류의 개체 간 상호 영향**을 구현한 첫 플레이 구간이다.
문서의 39개 WBG 노드를 전부 실행하는 범용 그래프 엔진, 초반 1막 전체(A101/A103~A107)의 계약·운송·시설 정비·세력 관리권, 오룬 맵과 실제 월드 간 이동은 아직 아니다.
번식·새끼 성장·이주·개체 승격, 완전한 자원 원장/관계 그래프/증거 확신·사법 판결, 작업 책임자의 정교한 승계와 NPC 건물 실내 생활도 남아 있다.
일부 enum 값은 문서 ID를 보존하기 위해 선언했으나 모든 노드를 실행하지 않는다. 동일 행동 안의 접근·회피는 간소화했다. 죽음·신고·거래가 구현되었다는 사실을 영속 사회 시뮬레이션 전체 완성으로 해석하지 않는다.
사건 원장은 세션 동안 보관되므로 장시간 실행에서는 `lena.fact_count`와 `lena.observe`를 함께 확인한다. 저장 크기는 16 MiB, 로드 허용 사실 수는 100,000개다.

## 사용자 확인 항목

빌드·실행·시각 결과와 밸런스 검증은 수행하지 않았다.

빌드 후 `SimpleGame.exe --lena-self-test`로 창을 열지 않는 기본 회귀 검사를 실행할 수 있다.
초기 개체 수/연결 스폰, 사망 1회 처리, 원거리 지식 차단, 신고 중복 방지, 항복 보호,
늑대 Kill gate, 유한 사체 섭식, NPC 치료/거래 자원 보존, 리아 사망 대체 경로,
전체 저장 복원과 잘못된 저장의 원자적 거부를 확인한다. 테스트는 시스템 임시 폴더의
고유 파일만 사용하고 종료 시 제거하며 실제 사용자 저장 슬롯은 건드리지 않는다.
이 검사도 이번 작업에서는 실행하지 않았다. 렌더링/장기 시뮬레이션 검증을 대신하지 않는다.

1. 무인자/--lena 실행 시 수로에서 시작하는지, --tutorial/--level-one은 그대로인지.
2. 처음 H로 시작 후 1/2 선택, 30분 미개입, 게시판 조사 선택과 120분 미개입 경로.
3. 수로→광장→숲 이동, 충돌, 미니맵, 스프라이트/그림자/수면/후처리 확인.
4. NPC 84명·약탈자 4명·늑대 7마리·사슴 32마리 초기 수와 모니터 집계 비교.
5. 숲에서 늑대-사슴 추격/반격/사망/섭식 확인. 사체 열량이 음수가 되거나 먹이 사망 전에 먹이가 생기지 않는지.
6. 약탈자-주민-경비 갈등, NPC 치료, 항복자 공격 중단, 근접 구금 상태 확인.
7. 리아 또는 에드윈을 플레이어 공격으로 죽인 후 인구가 한 번만 줄고 게시판/수로 조사 경로가 남는지.
8. 가까운 목격자만 정보를 얻고 신고 도착 전후 reported/치안 변화가 한 번 발생하는지.
9. K 저장→사망/자원 사용→L 로드 시 플레이어뿐 아니라 세계 상태 전체가 복원되는지.
10. 저장 파일을 백업한 뒤 잘못된 버전/ID/NaN/중복 사망을 넣어 로드 거부와 현재 상태 보존 확인.
11. H에서 시간·AI·작업이 멈추고 모니터에는 paused가 표시되는지.
12. 현장 복구 120분, 위험 시 작업 중단, 사냥 후 늑대 수 감소, 재생성되지 않는지.
13. Release에서 lena.simulation/decide/observe/pathfind/terrain_submit/hud와 기존 render/world draw call 측정. 성능 향상을 아직 단정하지 않는다.
