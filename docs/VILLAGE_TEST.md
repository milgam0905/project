# 마을 행동 테스트 — storyline1

## 실행 및 범위

- 인자 없이 실행하면 확장 마을로 시작한다. `--village`와 기존 `--tutorial`도 같은 마을을 연다.
- 기존 첫 레벨 사냥터는 `--level-one`으로 실행한다. 모드 인자가 여러 개면 마지막 지정이 우선한다.
- 창 제목 `Storyline1 / Expanded Village Test`와 상단 HUD `마을 테스트 | NPC 36`으로 확장 마을 실행을 확인한다.
- 기존 마지막 장례/호수 퀘스트와 세계관 골격을 유지한다. story1.md의 아에리아 역사·메인 퀘스트로 교체한 것은 아니다.
- 맵은 56×52에서 112×104 월드 단위로 확장했다. 가로·세로 2배, 면적 4배다.
- 기존 주민 16명 + 신규 20명 = 36명. 기존 야생동물 9마리 + 적대 야수 48마리.
- 신규 주민: 리아, 에드윈, 상단 중개인 마라, 다리안, 노아, 셀린, 성직자 아벨, 헌금징수인 로단,
  상인 이네스, 밀수상 케른, 호위병 유나, 경비 폴, 농부 다나, 장의사 조수 루스,
  유물학자 오스, 순례자 네브, 산적 바르·렉스·테오·니아.
- 장의사 마라와 상단 중개인 마라는 기존 퀘스트 보호를 위해 서로 다른 인물로 표시한다.
- 여섯 주요 NPC의 일곱 성격 수치는 원문을 따랐다. 추가 인물과 생활 위치·수치·서비스 가격은 테스트용 제안이다.

## 조작

- WASD 이동, E 대화/조사, SPACE 근접 공격(누르고 있으면 0.45초 간격).
- T는 가까운 상인에게 식량 구매/즉시 섭취, 치료사에게 치료 요청. 대화 도중에도 T로 동의 가능하다.
- 상인은 재고와 대금이 있어야 거래한다. 탐욕 75 이상은 은화 5개, 나머지는 3개. 식량 1개로 HP 20 회복.
- 치료사는 약초 1개를 소비한다. 요청 치료 HP 35, 자율 구조 HP 20. 무한 재고는 아니다.
- F는 테스트용 몹 보충 ON/OFF. 기본 ON, 처치 후 25초 이상 + 플레이어가 출생 위치에서 10단위 넘게 떨어져야 보충한다.
- R 전체 초기화, H 도움말, ESC 대화 닫기/종료. 대화·도움말 동안 세계 시간과 AI/재생성은 정지한다.
- 시작 은화 30, HP 100. 야수 직접 처치당 은화 3. HP 0이면 마을로 복귀/HP 회복: 테스트 편의 기능이다.
- 상단 HUD에서 세계 시각·HP·은화·처치·보충 설정, 가까운 NPC 위에서 이름/현재 행동을 확인한다.
- 늑대·멧돼지는 마을 밖 세 고리(반경 약 17/29/41)에 분산된다. 산적 주둔지는 대체로 동남쪽 (23~31,14~21), 탈주자는 서쪽이다.
- 경비 유나는 동남쪽 교역로를 순찰한다. 야수를 마을 외곽에서 만나거나 산적에게 접근하여 경계·도주·보호를 관찰한다.

## 문서 패턴의 적용

- WBG 노드 번호는 원문을 유지한다. 이번 구현은 39개 전체 엔진이 아닌 마을 행동 수직 슬라이스다.
- Evaluate/Observe/Remember/Decide는 상태 평가 단계다. 관찰은 0.25초, 판단은 1초 주기이며 NPC별 시작 시점을 분산한다.
- 행동 실행 가능 조건을 먼저 확인하고 기본값+욕구+성격+환경+목표+기억+결정적 변동(-3~3)을 비교한다.
  관계·복합 감정 항은 이번 슬라이스에서는 미구현이다. 동일 점수는 현재 행동, 그다음 낮은 노드 번호를 우선한다.
- 현재 행동 최소 2초/12점 차이의 전환 억제를 적용한다. 위험이나 실행 불가는 즉시 다시 선택할 수 있다.
- 배고픔/갈증/피로와 보유 자원이 식사·음수·휴식·수면을 결정한다. 시간은 실제 1초당 게임 1.2분, 06시 시작이다.
- 직업별 작업장/조사 지점으로 이동한다. 리아는 주간 호수 제단 조사, 에드윈은 창고→민원→배급 위치를 시간대별 방문한다.
  야간에는 자택 주변에서 잔다. 건물 내부 및 생산/배급 경제는 아직 구현하지 않았다.
- 친절한 치료사는 가까운 부상 플레이어를 돕는다. 재고는 Actor 내부에 보관하고 실제로 소모한다.
- 경비는 직접 볼 수 있는 야수 및 공격 중인 산적을 대상으로 보호 행동을 한다.
- 일반 주민/겁 많은 경비는 용기와 위험 기억에 따라 도주를 더 선호한다.
- 산적은 먼저 위협하고, 공격성이 높은 경우 경고 이후 접근·공격한다. 낮은 용기의 탈주자는 도주를 선호한다.
- 산적 HP가 25 이하이면 항복하며 다시 공격하지 않는다. 경비와 플레이어 모두 항복자를 추가 타격하지 않는다.
- 관측은 거리+정적 장애물 선분 검사다. 최근 직접 관측한 위험 ID/공포를 제한 시간 보관한다.
  정교한 시야각·청각·목격자 원장·범죄 수사·증거 전파는 아직 아니다.
- 조사/노동은 이동·체류 패턴만 구현했다. 유물 지식 생성이나 생산 보상은 만들어 내지 않는다.

## 구조와 성능

- NPC/야수는 SceneGraph 소유 Actor이며 게임 모드는 ID만 보관한다.
- 기존 주민도 동일한 욕구·판단 로직을 사용한다. 퀘스트 제공자만 원래 위치에 고정하여 기존 동선을 유지한다.
- 나무/건물/물/경계를 0.5단위 보행 격자에 굽고 시작점 연결 영역만 사용한다. 모든 출생/목적지는 이 영역으로 보정한다.
- 이동은 선분 검사 후 필요할 때 경로를 찾는다. 업데이트당 최대 3회 탐색, 1.5초 재탐색 간격. 미처리 요청은 이후 프레임에서 재시도한다.
- 확장 외곽은 숲 밀도를 낮추고 기존 곡선 길을 연장했다. HUD 미니맵 축척도 절반으로 변경했다.
- RenderQueue와 기존 캐릭터/야수 아틀라스를 재사용한다. 나무/건물은 기존 도형 외형을
  village_scenery_v1 아틀라스로 구워 기존 AssetCache 포맷으로 저장한다. 연기/흔들림은 동적으로 남긴다.
- 안전 위치는 초기 다중 시작점 BFS 표로 조회한다. 정확한 유클리드 최단점 대신 연결 영역의 격자 최근접점을 쓴다.
- 프레임 지연은 고정 업데이트 누적으로 처리한다. 2초를 넘는 디버거 정지 등은 명시적으로 제한하고 로그에 남긴다.

## 의도적으로 남긴 범위

- 영속 저장/로드, 완전한 39개 노드 그래프, 경제·자원 원장, 추상 시뮬레이션 LOD, 관계/범죄/죽음 연쇄, story1의 퀘스트 체인은 미구현이다.
- 민간인/주요 NPC의 영구 사망은 없고 산적은 비살상 제압된다. Kill 노드는 실행하지 않는다.
- 적대 야수는 전투 테스트 AI이며 문서의 늑대-사슴 생태계/굶주림 기반 사냥 모델이 아니다. 기존 9마리 동물은 기존 배회/도주를 유지한다.
- 몹 보충은 영속 생태계 규칙의 예외인 테스트 기능이며 Actor 슬롯을 재사용한다. 영속 세계로 전환할 때 새 개체 ID/이주 사건으로 대체해야 한다.
- NPC끼리 거래/치료하는 전체 사회 시뮬레이션은 없고 이번 거래·치료 대상은 플레이어다.
- 보행 격자는 초기 배치만 반영한다. 런타임 장애물 변경 시 다시 굽는 처리가 필요하다.

## 사용자가 빌드 후 확인할 항목

1. --village로 시작하여 HUD에 NPC 36과 시계가 보이는지, 기존 퀘스트가 끝까지 가능한지.
2. 외곽 네 방향 이동, 도로·물·건물 충돌, 미니맵, 카메라와 가림 정렬.
3. 리아/에드윈의 이동, 서로 다른 주민의 식사/휴식, 위험 시 도주와 경비 보호.
4. 상인의 재고/은화가 한 번씩 이동하는지, 재고/돈 부족 시 거래 실패, 치료 약초 소모.
5. 산적 경고 후 공격, SPACE 제압 후 항복, 항복 상태에서 추가 공격이 없는지.
6. 야수 처치 보상 단일 지급, 25초 후 멀리서만 보충, F OFF에서 보충되지 않는지.
7. H/대화 중 시계·AI·공격·보충 정지, R 초기화 시 중복 Actor가 남지 않는지.
8. Release 프로파일에서 navigation.village_pathfind, ai.village_decision, scene.update/render와 draw call 비교.
9. 첫 실행 아틀라스 생성/다음 실행 캐시 적중, 나무·건물 가장자리/투명도/흔들림/연기 확인.
10. render.world CPU, 배치 분리, 버퍼 업로드 감소 여부 및 저프레임의 시계/이동 속도 확인.

빌드·실행·시각 및 성능 검증은 수행하지 않았다. 실제 결과는 위 수동 확인이 필요하다.
