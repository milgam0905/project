# ARCANA resource 변환 및 배치

게임 실행/빌드 없이 오프라인에서 준비한 파생 에셋이다. 원본 `resource/ARCANA_lowpoly_v1`은 변경하지 않았다.

## 파일

- 원본: `resource/ARCANA_lowpoly_v1` — GLB, Blender, PBR 이미지와 메타데이터.
- 변환 도구: `tools/bake_arcana_resources.py` — Python + numpy + Pillow.
- 게임용 캐시: `resource/ARCANA_runtime` — 1,255개 항목, 2048×2048 PNG 5장, 풀/흙/돌 PNG.
- 실행 파일 옆 배포: `assets/arcana_lowpoly` — Visual Studio 빌드 후 자동 복사.
- 로더: `SimpleGame/ResourceSprites.*` — Windows WIC 디코더, 추가 다운로드 라이브러리 없음.
- 배치: `LenaGame::Impl::PlaceResources`, 기존 집·나무·인물 Actor 콜백.

## 원본 변경 시

프로젝트 루트에서 `python tools/bake_arcana_resources.py` 실행 후 사용자가 빌드한다.
원본 GLB·지면 이미지·변환 코드의 SHA-256이 같으면 기존 캐시를 재사용한다.
게임 실행 시 Python/Blender가 필요하지 않으며 실시간 GLB 변환도 발생하지 않는다.
파생 PNG와 `sprites.txt`는 함께 배포해야 한다. 캐시가 없으면 옛 도형으로 조용히 돌아가지 않고 오류를 알린다.

## 변환 범위

GLB 2.0의 삼각형, 노드 TRS/행렬, 역바인드/스킨 가중치, STEP/LINEAR 애니메이션,
최단 경로 쿼터니언 보간, UV0·내장 Base Color, 깊이 버퍼와 고정 방향광을 사용한다.
현재 팩의 실제 형식에 맞춘 변환기이며 범용 glTF 엔진은 아니다.
압축 메시·sparse accessor·morph·CUBICSPLINE·외부 이미지·실시간 PBR·IK는 대상 밖이다.

인간 4종 및 동물 4종에 대기/걷기/공격 8방향×6프레임, 사체 8방향을 베이크한다.
방향 번호는 화면 기준 아래→오른쪽 아래→오른쪽 순서다. 균일한 월드 회전각이 아니라
2:1 투영의 역변환으로 각 화면 방향에 맞는 메시 회전각을 계산한다.
런타임도 월드 이동 벡터를 화면으로 투영한 뒤 동일한 8방향으로 고른다.
사망 클립은 팩에 없으므로 전방 +Z 축을 중심으로 옆으로 눕힌 정적 사체다.
머리-엉덩이 축은 수평으로 유지하며 몸 중심을 배치 원점에 맞추고 최저점을 바닥에 접지한다.
생존/사망은 여전히 게임 상태가 결정한다. 동작 전환 혼합·완전한 개별 NPC 모듈 조립은 미구현이다.
캐시 헤더는 `ARCANA_SPRITES_3`이며, 이전 4방향 캐시는 로더에서 거부한다.

## 게임 배치

플레이어는 주인공, 주민은 villager, 경비·산적은 guard, 브란은 blacksmith 프리셋이다.
기존 멧돼지/늑대/사슴의 종별 메시와 각 집/나무를 교체했다. 염소는 캐시에만 있으며 새 종 AI를 만들지 않았다.
우물은 음수 위치, 모루·망치·장작은 대장간, 식탁·의자·상자·자루는 마을 장터,
등불·토기는 집 주변, 고사리·관목·버섯·바위는 숲, 갈대는 호숫가에 배치한다.
장식은 SceneGraph 소유 Actor이며 통행을 막는 새 충돌체를 만들지 않는다.
불탄 집은 그을린 기초/기둥과 조사 가능한 유품 상자로 표현한다.
곡선 길·지형·호수·미니맵과 기존 집/나무 충돌은 유지한다.
지면은 제공 풀/흙/돌 이미지를 사용하고 물결·불꽃·파란 구체는 기존 효과를 유지한다.

기존 보존 모드는 변경하지 않고 ARCANA만 리소스 경로로 전환했다.
아틀라스는 비압축 RGBA 기준 80MiB이며 지면 3장/후처리/드라이버 메모리는 별도다.
투명 Actor를 텍스처 기준으로 임의 재정렬하지 않는다. 따라서 1,255개 항목이 1,255 draw call을 뜻하지 않는다.

게임 빌드·실행·화면 결과·FPS 개선은 이번 작업에서 검증하지 않았다.
